# pykorail is installed from the wheel in vendor/, not from PyPI: the project
# was deleted from PyPI on 2026-11-02 (~19:05 KST) and every poll failed at

# a stranger re-registering the freed name cannot slip a build in either.

#

# runner installs on every poll, so a floating range would let any new
# release go live untested. Dependabot opens a PR per new version and
# tests.yml runs against it first. CI cannot reach the live backend (it
# refuses datacenter IPs), so after merging a bump watch for a 감시 중단
